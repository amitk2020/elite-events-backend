# Elite Events – Backend API

This is the backend API for **Elite Events**, an event management platform built with **Symfony 8** and **MySQL**.  
It provides RESTful endpoints to manage events and includes an admin panel powered by **EasyAdmin**.

---

## 🚀 Tech Stack

- **PHP 8.2+**
- **Symfony 8**
- **Doctrine ORM**
- **MySQL**
- **EasyAdmin 4**
- **Nelmio CORS Bundle**

---

## 📁 Features

- REST API for events (`/api/events`)
- Admin dashboard (`/admin`)
- CRUD operations for events
- MySQL database integration
- CORS enabled for frontend communication
- Environment-based configuration (dev / prod)
